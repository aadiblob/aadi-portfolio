# Aaditya Patil — Engineering portfolio starter

A near-black, technical portfolio foundation built with Next.js, TypeScript, Tailwind CSS, Motion, and the Cloudflare OpenNext adapter.

## Included

- Responsive dark visual system
- Fixed navigation and scroll progress
- Animated engineering hero graphic
- Interactive wheel FEA placeholder with CAD / mesh / stress modes
- Animated roots-supercharger line drawing
- High-contrast Copeland experience section
- Reusable reveal animation
- Cloudflare Workers configuration
- Reduced-motion accessibility behavior
- SEO metadata, sitemap, robots, and web manifest

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
npm run deploy
```

Read `START-HERE.md` for the complete Windows, GitHub, Cloudflare, and custom-domain workflow.
