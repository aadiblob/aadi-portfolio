# Portfolio V3.6 — Supercharger Right Shift

This root-flat patch changes only the desktop positioning of the supercharger viewer.

- Moves the rendered 3D supercharger farther right: `translateX(3.5%)` → `translateX(11%)`.
- Keeps the current model size, materials, lighting, axis correction, and turntable controls unchanged.
- Tablet and mobile layouts remain centered.

No dependency installation is required.
